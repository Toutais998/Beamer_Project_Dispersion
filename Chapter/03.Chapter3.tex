        \end{column}
        \begin{column}{.48\textwidth}
            \begin{itemize}
                \item 主要工作波段的 RMS 水平进一步降低，且随视场增大的变化更平缓。
                % \item 轴上像点，也提高了扫描过程中的全场像质一致性。
            \end{itemize}
        \end{column}
    \end{columns}
\end{frame}

        \begin{column}{.64\textwidth}

                \centering
                \includegraphics[width=\textwidth,height=.58\textheight,keepaspectratio]{Figure/ZemaxSimulation/RMS_03.jpg}

    \end{columns}

    \vspace{-4pt}
    \begin{itemize}
        \item 左图用于说明低空间频率下切向与弧矢 OTF 的解释方式；右图同时给出波前误差与对比度保持能力。
        \item 优化后，910/920/930 nm 三条曲线在主工作视场内保持较低 RMS，且切向与弧矢 OTF 均接近 1。
        \item 系统在边场扫描时仍能维持稳定的低频结构传递能力。
    \end{itemize}
\end{frame}

    \vspace{-4pt}
    \begin{itemize}
        \item 虚线框对应标准 $\pm 3^\circ$ 扫描工作区，框外部分用于观察更大扩展视场下的几何失真。

    \end{itemize}
\end{frame}

    \begin{itemize}

        \item 前述低 RMS 和高 OTF 相一致，说明优化后设计在主工作视场内具有较高的波前保真度。
        % \item 对长工作距多光子物镜而言，这表明在保留机械空间的同时，系统仍能维持较高的像质上限。
    \end{itemize}
\end{frame}
