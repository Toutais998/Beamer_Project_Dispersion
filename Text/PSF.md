# 点扩散函数 (PSF) 与图像反卷积

**摘要：** 点扩散函数（Point Spread Function, PSF）是理解光学系统成像质量的基础。本文整理了理想 PSF 的物理意义，探讨了它在实际应用中遇到的挑战，并详细介绍了利用反卷积技术恢复图像质量的数学原理与常用算法。

## 1. 什么是点扩散函数 (PSF)？

在理想的光学系统中，**点扩散函数（PSF）\**是从样本中无限小的点光源发射、通过高数值孔径 ($NA$) 物镜传输到像平面的光的三维衍射图案。它是图像形成理论模型中的\**基本单位**。

当光从点物体发射时，物镜并不能将其完美聚焦成一个无限小的点。相反，由于衍射效应，光波会在焦点处会聚并发生干涉，在 $x-y$ 平面上形成一个中心明亮、周围环绕同心光环的衍射图案——这就是著名的**艾里斑（Airy Disk）**。中心亮斑的半径由数值孔径 ($NA$) 决定，通过测量艾里斑的大小可以评估系统的分辨率。

## 2. 分辨率与瑞利极限

半峰全宽 (FWHM) 常用来描述 PSF 的宽度，进而定义物镜的横向分辨率和**瑞利极限 (Rayleigh Criterion)**。在没有球差的完美透镜中，点源的衍射图案在横向和轴向是具有特定对称性的（通常呈沙漏形或橄榄球形）。两个相邻发光点在像面上形成的衍射斑能够被分辨的最小距离，决定了显微镜的横向和轴向分辨率。

## 3. 实际中的 PSF 与卷积成像模型

理论上我们可以用嵌入凝胶的荧光微球来测量理想 PSF。然而，生物标本等实际样品通常是不均匀的，组织或细胞内不同区域的折射率变化会导致光线散射和衍射，使实际的 PSF 偏离理论计算值。

在假设成像过程满足**线性**和**空间平移不变性**的前提下，样本的最终图像 $i(r)$ 可以看作是真实发光物体 $o(r)$ 与光学系统的 $PSF(r)$ 之间的**卷积 (Convolution)**：

$$i(x,y,z) = o(x,y,z) \otimes PSF(x,y,z)$$

连续域的卷积积分表达式为：

$$i(x) = \int_{-\infty}^{\infty} o(x-x') \times PSF(x') dx'$$

## 4. 频域分析与光学传递函数 (OTF)

在空间域中处理三维卷积的计算量极其庞大。通过**傅里叶变换 (Fourier Transform)**，我们可以将空间坐标 $(x,y,z)$ 转化为空间频率。在频域中，复杂的卷积运算简化为了逐点乘法：

$$F\{i\} = F\{o\} \times F\{PSF\}$$

这里，$F\{PSF\}$ 的傅里叶变换结果被称为**光学传递函数 (Optical Transfer Function, OTF)**。OTF 描述了显微系统如何传递不同空间频率的信号。一般来说，显微镜相当于一个低通滤波器：

- **低频成分**（大尺寸、平滑特征）容易通过。
- **中高频成分**（细节）被逐渐衰减。
- 超过截止频率 $2NA/\lambda$ 的**极高频成分**则完全丢失。

## 5. 反卷积 (Deconvolution) 图像恢复技术

由于光学衍射会导致图像**模糊 (Blur)** 以及焦外背景光的干扰，反卷积技术应运而生。它是基于点物体及其 PSF 卷积模型，利用数学算法将离焦光“重新分配”回其原发光点，从而大幅提高对比度和分辨率。

理论上，通过对上式求逆，可以直接获得真实物体的信息：

$$F\{o\} = \frac{F\{i\}}{OTF}$$

但是，实际图像中不可避免地存在噪声。直接反滤波会极大地放大高频噪声，使得结果完全失真。因此，现代反卷积算法必须引入关于物体的先验约束（如平滑度、非负性）以及相关的噪声模型。

### 主要反卷积算法分类：

- **去模糊算法 (Deblurring):** 例如最近邻法 (Nearest-Neighbor)。它通过从当前焦平面减去上下相邻平面的模糊估计来锐化图像。这类算法运行速度快、占用内存小，但未考虑远距离层间的串扰，可能会降低信噪比 (SNR)，且容易引入伪影，因此不能用于定量的形态测量或强度比计算。
- **图像恢复算法 (Image Restoration):** * **约束迭代方法 (如 Jansson-van Cittert):** 通过设定非负限制等约束条件，不断预测图像、计算误差并迭代修正。这种方法在降低高频噪声方面非常有效。
  - **盲反卷积 (Blind Deconvolution):** 不需要预先输入准确测量的 PSF。算法会通过迭代，同时估计出最可能的物体分布和真实的系统 PSF。这对于折射率不均、实际 PSF 发生劣化的复杂生物样品尤为有效。

**总结：** 反卷积过程涉及海量的浮点运算（尤其是 3D 图像堆栈），对 CPU 和内存的算力要求极高。在实际应用中，选择合适的算法需要在分辨率提升、处理速度和噪声控制之间取得微妙的平衡。
